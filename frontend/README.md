# TerraLens Frontend

Modern, dark-first React 19 application built with TypeScript, Vite, Tailwind CSS, MapLibre GL JS, and Recharts.

## Scripts
- `npm run dev`: Start local development server on port 5173.
- `npm run build`: Compile production build.
- `npm run preview`: Preview production build locally.
- `npm run lint`: Run TypeScript type-checker.
